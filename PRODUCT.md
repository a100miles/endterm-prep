# Endterm Prep
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User-specified React, TypeScript, Vite, Tailwind CSS v4, shadcn/ui, Lucide, Motion, React Router and LocalStorage. GitHub Pages at a100miles/endterm-prep.
## Users
A university student preparing for an AWS Cloud Developing endterm tomorrow, studying on desktop and mobile.
## Product Purpose
Read source-traceable explanations, recall concepts, practise questions, simulate an exam and revisit mistakes.
## Constraints
Six supplied lecture decks and five Quizlet sets are the content authority. Preserve original answers and flag errors explicitly. No invented progress or implied AI grading. Local-only persistence. All five question formats. Keyboard access, reduced motion and dark mode.
## Brand Commitments
The user has specified warm off-white surfaces, dark typography, subtle accents, rounded cards and a minimal Linear/Notion/Quizlet-style interface. Content accuracy takes priority over decoration. The user delegated routine implementation choices and requested autonomous completion.
## Evidence
441 supplied slides, including editable diagram appendices. Quizlet source access documented per set. No Module 1 Quizlet set was supplied.
